# JavaLab2

Лабораторная работа №2 «Знакомство со средой разработки Eclipse».

## Структура проекта

- `src/lr2` — задачи для самостоятельной работы (Task1–Task5)
- `src/timus` — решения задач с сайта acm.timus.ru:
  - `timus_1068` — задача 1068 «Сумма»
  - `timus_1083` — задача 1083 «Факториалы!!!»
  - `timus_1264` — задача 1264 «Трудовые будни»

## Отправка на Timus

Для отправки решения на проверку класс следует переименовать в `Main`
и удалить строку `package ...` из начала файла.

## Тестовые данные

- 1068: вход `-3`, выход `-5`
- 1083: вход `9 !!`, выход `945`
- 1264: вход `3 1`, выход `6`
